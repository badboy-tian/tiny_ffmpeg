# Product Overview

tiny_ffmpeg is a lightweight Flutter plugin that provides FFmpeg functionality for iOS, Android, and OpenHarmony (OHOS) platforms.

## Core Features

- Execute FFmpeg commands asynchronously with session management
- Extract video thumbnails
- Get media file duration
- Cancel running FFmpeg operations
- Progress tracking via event channels
- Detailed error reporting

## Target Platforms

- iOS 10.1+
- Android (minSdkVersion 16+)
- OpenHarmony (OHOS)
- Flutter 1.20.0+

## Key Use Cases

- Audio/video processing and conversion
- Media file manipulation (mixing, filtering, encoding)
- Thumbnail extraction from videos
- Audio effects (volume adjustment, delays, mixing)

## Distribution

Distributed via Git repository, not published to pub.dev. Users install by referencing the GitHub repository in their `pubspec.yaml`.
